Dev Toolbox

Everything runs in your browser. Nothing you paste here is sent anywhere.

JSON formatter

Paste JSON to check it, pretty-print it, minify it, or explore it as a tree.

JWT decoder

Shows a token's header and claims. The signature is not checked, because that needs the signing key.

Base64 & URL encoding

Type on either side and the other side updates. Text is treated as UTF-8.

Unix timestamp converter

Paste a timestamp in seconds, milliseconds, microseconds or nanoseconds, or a date like 2026-10-24T09:30:00Z.

Now:

UUID & ULID generator

v4 is random. v7 and ULID start with the time, so they sort in the order they were made.

Hash generator

SHA hashes of text or a file. MD5 isn't included because browsers don't provide it, and it shouldn't be relied on.

Regex tester

JavaScript regular expressions. Matches are highlighted as you type.

//
Flags: g all matches · i ignore case · m multiline · s dot matches newline · u unicode · y sticky

Text diff

Line-by-line comparison. Removed lines are red, added lines green.

Cron explainer

Five fields: minute, hour, day of month, month, day of week. GitHub Actions and most servers read these in UTC.

CIDR / subnet calculator

IPv4. Enter an address with a prefix like 10.0.12.34/20, or with a netmask like 192.168.1.10 255.255.255.0.

Timezone meeting planner

Pick a date and an hour in the first zone to see that moment everywhere else. Shaded hours are 9:00 to 18:00.

HTTP status codes

chmod calculator

Tick permissions or type an octal value like 755 or 4755.
